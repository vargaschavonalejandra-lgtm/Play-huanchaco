# Play-huanchaco
PLAY HUANCHACO es una plataforma interactiva inspirada en juegos multijugador de Play Store, con minijuegos arcade, quiz turísticos y desafíos dinámicos sobre Huanchaco. Diseñada para jóvenes y adultos, integra QR en llaveros y pulseras de tortuga para vivir una experiencia turística moderna, divertida y educativa.
